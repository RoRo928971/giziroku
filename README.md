# giziroku（議事録作成アプリ）

社内会議の議事録作成を支援する Web アプリです。会議名・日時・出席者・議題・決定事項・ToDo などを
フォームに入力すると、整った議事録としてライブプレビューされ、そのまま **PDF 出力** できます。

## 特長

- 📝 **フォーム入力**：基本情報／議題／決定事項／アクションアイテム（ToDo）／備考を構造的に入力
- 🤖 **AIによる自動要約・整形**：会議のメモ書きや文字起こしを貼り付けるだけで、Claude が議題・決定事項・ToDo などに自動で振り分け
- 👀 **ライブプレビュー**：入力しながら完成イメージをリアルタイム確認
- 🗂 **複数の議事録を管理**：ブラウザの localStorage に保存・読込・削除
- 📄 **PDF 出力**：ブラウザの印刷機能で出力。日本語フォントもそのまま綺麗に出力されます
- 💾 **JSON バックアップ／復元**：別 PC への移行やバックアップに対応

## 使い方

### 方法 1：付属サーバーで起動（推奨）

```bash
npm start
```

ブラウザで <http://localhost:3000> を開きます。
（ポートを変えたい場合は `PORT=8080 npm start`）

### 方法 2：ファイルを直接開く

`public/index.html` をブラウザでダブルクリックして開くだけでも動作します。
（ただし後述の **AI整形機能** はサーバー経由でのみ利用できます）

## AIによる議事録の自動要約・整形

会議のメモ書きや文字起こしを貼り付けて「整形する」を押すと、Claude が内容を読み取り、
議題・決定事項・アクションアイテム（ToDo）・出席者などに自動で振り分けてフォームへ反映します。

### セットアップ

AI機能には Anthropic の API キーが必要です。サーバー起動時に環境変数で渡してください。

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
npm start
```

- 使用モデル：`claude-opus-4-8`（アダプティブ思考 + 構造化出力で安定した整形）
- API キー未設定の場合、通常の手入力・PDF出力は問題なく使えます（AI整形のみ無効）。
- 入力した会議メモは整形のために Anthropic の API へ送信されます。機微情報の取り扱いにご注意ください。

### 使い方

1. ヘッダー下の **「🤖 AIで議事録を整形」** を開く
2. 会議メモ／文字起こしを貼り付ける
3. **「整形する」** をクリック（既存内容に追記するか上書きするか選択可）
4. 反映された内容を確認・修正し、保存／PDF出力

## PDF として保存する手順

1. 議事録を入力し、ヘッダーの **「PDF出力」** ボタンをクリック
2. ブラウザの印刷ダイアログが開きます
3. 送信先（プリンター）で **「PDFに保存」** を選択して保存

> 用紙サイズは A4 を想定したレイアウトになっています。

## データの保存場所

入力した議事録は **お使いのブラウザの localStorage** に保存されます。
別の PC やブラウザに移したい場合は、サイドバー下部の
**「JSONバックアップ」** で書き出し、移行先で **「JSON読込」** から取り込んでください。
